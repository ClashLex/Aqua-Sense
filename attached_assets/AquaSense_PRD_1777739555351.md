# AquaSense 2.0 — Product Requirements Document
### "From Prototype to Platform"
**Buildathon Project | Replit Agent Build | 24-Hour Sprint**

---

## 1. Project Overview

AquaSense 2.0 is a real-time IoT-based smart water quality monitoring platform with AI-powered anomaly detection, predictive alerts, and an intelligent water quality chatbot. It transforms raw sensor data into actionable insights — making unsafe water visible before it becomes dangerous.

**Origin:** Started as an academic IoT project (S2 CSE, KMEA Engineering College). This buildathon evolves it into a deployable platform.

**Live Demo Goal:** A fully functional web app running on Replit with simulated sensor data, real-time charts, AI anomaly detection, and an embedded AI assistant.

---

## 2. Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS v3
- **Charts:** Recharts
- **AI Chatbot:** Claude API (`claude-sonnet-4-20250514`) via `fetch` to `https://api.anthropic.com/v1/messages`
- **Backend (optional):** Node.js / Express for sensor data simulation API
- **Deployment:** Replit (single project, fullstack)
- **Icons:** Lucide React
- **Animations:** Framer Motion

---

## 3. Design Direction

**Aesthetic:** Dark cyberpunk-industrial. Deep navy/black backgrounds. Neon cyan (`#00f5ff`) and neon green (`#39ff14`) as primary accent colors. Amber/red (`#ff6b35`) for alerts and danger states.

**Font Pairing:**
- Display / Headers: `Orbitron` (Google Fonts) — futuristic, technical
- Body / Data: `JetBrains Mono` — monospaced, feels like real sensor data

**Visual Identity:**
- Glowing card borders with subtle pulse animations on live data
- Scanline overlay effect on the dashboard background (CSS only)
- Animated status indicators (pulsing dots for live/offline sensors)
- Numbers animate/count-up on load
- Alert cards shake + flash red when anomaly is detected

**Layout:** Full-width dark dashboard. Sidebar nav on desktop, bottom nav on mobile. Fully responsive.

## 4. Pages & Features

---

### Page 1: Dashboard (Main)

**Route:** `/`

**Purpose:** Real-time overview of all water quality metrics.

**Components:**

#### 4.1 Header / Navbar
- Logo: "💧 AquaSense" in Orbitron font, cyan glow
- Status pill: "● LIVE" (green pulsing dot) or "⚠ OFFLINE" (red)
- Last updated timestamp (updates every 5 seconds)
- Nav links: Dashboard, Analytics, Alerts, Assistant

#### 4.2 Sensor Metric Cards (top row)
Display 5 key metrics in glowing cards. Each card shows:
- Metric name
- Current value (large, animated count-up)
- Unit
- Status badge: SAFE / WARNING / DANGER
- Mini sparkline (last 10 readings)

**Metrics to display:**
| Metric | Safe Range | Warning | Danger |
|---|---|---|---|
| pH Level | 6.5 – 8.5 | 6.0–6.5 or 8.5–9.0 | < 6.0 or > 9.0 |
| Turbidity | < 4 NTU | 4–10 NTU | > 10 NTU |
| Temperature | 15–25 °C | 25–35 °C | > 35 °C |
| Dissolved Oxygen | > 6 mg/L | 4–6 mg/L | < 4 mg/L |
| TDS (Total Dissolved Solids) | < 500 ppm | 500–1000 ppm | > 1000 ppm |

#### 4.3 Real-Time Line Chart
- Full-width chart below metric cards
- Shows all 5 metrics over the last 60 data points (each point = 5 seconds)
- Toggle buttons to show/hide individual metrics
- Built with Recharts `LineChart`
- Animated line drawing on load

#### 4.4 Sensor Location Map (simplified)
- A stylized card showing 3 simulated sensor nodes: "River Station A", "Treatment Plant B", "Distribution Point C"
- Each node shows its overall status (SAFE / WARNING / DANGER) as a colored dot
- Clicking a node filters the dashboard to show only that sensor's data

#### 4.5 AI Anomaly Alert Banner
- Appears at the top of dashboard when anomaly is detected
- Red glowing border, shake animation
- Text: "⚠ ANOMALY DETECTED — [Metric] at [Location] is [Value]. Recommended action: [action]"
- Dismiss button

### Page 2: Analytics

**Route:** `/analytics`

**Purpose:** Historical trends, pattern analysis, predictions.

**Components:**

#### 4.6 Time Range Selector
- Buttons: Last 1hr / 6hr / 24hr / 7 days
- Data is simulated but changes shape based on selection

#### 4.7 Metric Deep-Dive Charts
- Individual full-width charts per metric
- Shows historical readings + a dashed "predicted" line for next 2 hours
- Prediction is calculated using a simple linear regression on last 20 readings (implement in JS)

#### 4.8 Anomaly History Table
- Table of all detected anomalies
- Columns: Timestamp, Sensor, Metric, Value, Severity, Status (Resolved / Active)
- Color-coded rows (red = danger, amber = warning)
- Sortable columns

#### 4.9 Water Quality Score
- A large circular gauge (built with Recharts RadialBarChart)
- Overall score 0–100 calculated from weighted average of all metrics
- Color: green (80–100), yellow (50–79), red (0–49)
- Label: "EXCELLENT / GOOD / POOR / CRITICAL"

**Components:**

### Page 4: AI Assistant

**Route:** `/assistant`

**Purpose:** Chat interface powered by Claude API to answer water quality questions and analyze current readings.

**Components:**

#### 4.13 Chat Interface
- Full chat UI: message bubbles, user on right (cyan), AI on left (dark card)
- Input box at bottom with send button
- Typing indicator animation (three bouncing dots)

When the user sends a message, inject the current sensor readings into the system prompt automatically so the AI has full context:

#### 4.15 Quick Prompt Buttons
- Below input, show 4 suggestion chips:
  - "Is this water safe to drink?"
  - "What's causing high turbidity?"
  - "Predict pH trend for next 2 hours"
  - "Explain dissolved oxygen levels"

## 5. Data Simulation Engine

Since this is a demo, all sensor data must be simulated realistically in the frontend.

**Implementation (`useSensorData` custom React hook):**

```javascript
// Simulate realistic sensor readings that fluctuate over time
// Each metric has a base value + random walk + occasional anomaly spikes

const SENSORS = ['River Station A', 'Treatment Plant B', 'Distribution Point C'];

// Every 5 seconds, generate new readings for all sensors
// Occasionally (5% chance) inject an anomaly spike for drama
// Store last 60 readings per metric per sensor in state
// Export: currentReadings, history, activeAnomalies
```

**Anomaly Detection Logic:**
- Check every new reading against safe thresholds
- If value crosses WARNING or DANGER threshold for 3+ consecutive readings → trigger alert
- Anomaly object: `{ id, sensor, metric, value, threshold, severity, timestamp, resolved }`

**File:** `src/pages/Assistant.jsx`

```javascript
const sendMessage = async (userMessage) => {
  const currentReadings = getSensorReadings(); // from useSensorData hook
  
  const systemPrompt = `You are AquaSense AI, an expert water quality monitoring assistant.
Current sensor readings:
- pH: ${currentReadings.ph.value} (${currentReadings.ph.status})
- Turbidity: ${currentReadings.turbidity.value} NTU (${currentReadings.turbidity.status})
- Temperature: ${currentReadings.temperature.value}°C (${currentReadings.temperature.status})
```
